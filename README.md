# Web App Thống Kê Tuyển Sinh Lớp 10

## Cách chạy

### Cách 1: Dùng Python (nếu có)
```bash
cd "d:\DỰ ÁN\WEB TK TS10"
python -m http.server 3000
```
Mở trình duyệt: http://localhost:3000

### Cách 2: Dùng PowerShell HTTP Server
```powershell
.\serve.ps1
```
Mở trình duyệt: http://localhost:3000

### Cách 3: Dùng VS Code Live Server Extension
- Cài extension "Live Server" trong VS Code
- Right-click file index.html → "Open with Live Server"

## Lưu ý
- Cần kết nối internet (CDN libraries)
- Reload trang sẽ xóa toàn bộ dữ liệu
- Hỗ trợ trình duyệt: Chrome, Firefox, Edge (phiên bản mới nhất)
